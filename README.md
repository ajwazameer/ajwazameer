## Projects

**[Absolute Clothing](https://github.com/ajwazameer/absolute-streetwear-shop)**
Full e-commerce streetwear platform built for a private client — storefront, cart, checkout, and an admin panel with order and analytics management.
`TanStack Start` `Supabase` `Tailwind CSS`

**[Zaitoon](https://zaitoonpk.com)**
Live, full-stack restaurant ordering platform — menu management, orders, reviews, admin analytics dashboard, and a meal customizer. Co-built with a teammate.
`Next.js` `TypeScript` `Supabase`

**[Sightline AI](https://github.com/ajwazameer/sightline-ai)**
Voice-guided assistant for visually impaired users, using real-time camera input and LLM-powered scene description, including a dedicated obstacle-detection mode.
`React` `TypeScript` `Groq (Llama 4 Scout)` `Supabase`

**[OrderBot](https://github.com/ajwazameer/order-bot)**
LLM-powered customer service chatbot, developed from a DeepLearning.AI capstone into a deployed production app.
`Next.js` `Groq` `Vercel`

**Credit Card Fraud Detection**
Machine learning model using XGBoost to flag fraudulent credit card transactions.
`Python` `XGBoost`
